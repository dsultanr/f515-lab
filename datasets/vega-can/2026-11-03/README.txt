VEGA CAN — контрольный сеанс при полном заряде ВВБ, 2026-11-03

Условия: ВВБ в начале 100%, зарядный кабель отключён. Владелец подтвердил,
что при всех пяти измерительных Remote On ДВС и климат оставались выключенными.
Отдельного датчика RPM/состояния климата в этой выгрузке нет. Не подменять
наблюдение владельца утверждением об инструментальном подтверждении ДВС OFF.

Измерительный сценарий выполнен: 30 с OFF, 3 цикла On 45 с / Off 45 с,
затем 2 цикла On 45 с / Unlock 30 с / Lock 30 с. Задержки отправки и ожидания
окна CAN добавляются к этим выдержкам. Максимальный интервал между началом
команд: 54.959 с. Начальная команда setup_remote_off — подготовительная.
Далее 5 Remote On, 3 Remote Off, 2 Unlock и 2 Lock. Сценарий завершён.

1563506 кадров, 172 сочетаний шина/ID, шины 0/1/2.
CRC каждого исходного USB-пакета проверен; неполного хвоста нет. RX-индекс
покрывает каждый байт. dropped_bytes=0 относится к внутренней очереди,
а не ко всему трафику машины. Есть 197 наблюдаемых пауз >100 мс,
максимальная 2188 мс. Поток периодически перевзводится после
таймаута. Короткий кадр мог попасть в паузу; отсутствие кадра не доказывает
отсутствие команды. Методика перевзвода совпадает с сеансом 2026-11-02.

ДОПОЛНИТЕЛЬНЫЙ КОНТЕКСТ
Исходная непрерывная запись включает подготовку и восстановление связи.
Первый управляющий сценарий прервался после setup Remote Off из-за ADB.
Сам сборщик продолжал записывать CAN без перезапуска. Recovery Remote On
восстановил связь. Измерительные циклы находятся в attempt-2; не считать
подготовительные команды дополнительными измерительными повторами.
После завершения записи также выполнены retrieval Remote On / Remote Off
для восстановления сети и выгрузки. Они находятся вне интервала CAN.

ФАЙЛЫ
raw/stream.bin — исходные USB-пакеты Vega после авторизации, без изменений.
raw/rx_timing.csv — диапазоны байтов каждого USB RX, время ГУ wall/elapsed.
can/frames.csv — CAN в порядке получения; can/candump.log — по таймеру CAN.
В candump время относительно первого CAN-кадра, не Unix. can0/1/2 — сырые
номера шин Vega; физическое назначение и направление TX/RX не установлены.
context/packet_rx_timing.csv — RX-метки конца каждого CAN-пакета.
context/measured-scenario-commands.csv — команды согласованного сценария.
context/ha-command-log.json — реальные DEBUG TX/ответы интеграции HA.
Remote On сначала сбрасывает setting 1341 в 0, ждёт ACK и 1 секунду,
затем ставит 1. Сброс внутри Remote On не является отдельным Remote Off.
TX-метка ставится перед сетевой блокировкой, не равна физическому CAN TX.
context/ha-history.json — изменения выбранных сущностей HA и единицы.
context/ha_hv.csv — напряжение, ток и мощность ВВБ, асинхронные изменения.
context/hv-battery-current.csv — отдельно HV Battery Current в амперах.
История HA не является равномерной выборкой. Первая строка каждой сущности
может представлять восстановленное состояние на начало запроса.
context/attempt-*-scenario-events.jsonl — команды, проверки, состояния.
context/status.json, verification.json, runner.log — состояние и контроль.
collector/ — исходники помощника и локальных проверок; build.py зависит
от структуры исходного рабочего окружения, он не автономный SDK.
convert.py — автономный декодер: python3 convert.py raw/stream.bin OUTPUT.

ВРЕМЕННЫЕ ШКАЛЫ
За сеанс wall clock ГУ менялся скачками (25 поправок >100 мс).
elapsedRealtime оставался монотонным. USB RX имеет задержку относительно CAN.
Для совмещения сохранены packet_rx_timing, поправки verification.json и
замеры смещения часов host-hu-clock-calibration.jsonl через /proc/uptime;
нельзя использовать только started_ms + tracker_relative_ms как Unix time.
Вчера RX-метки не записывались: совмещение вчерашних HA/CAN приблизительное.

СРАВНЕНИЕ
Парный сеанс: 2026-11-02, ВВБ 11%, по наблюдению владельца ДВС запускался
при Remote On и глох при Remote Off / Unlock. Различие кадров между датами
само по себе не доказывает команду старта: отличаются SOC, напряжение,
температуры и состояние ДВС. Этот пакет — данные для исследования;
подтверждённой команды принудительного запуска ДВС в нём нет.
