# CAN Vega: контрольный сеанс при полном заряде ВВБ

3 ноября 2026 года, Evolute i-Space 4WD / F515. Заряд ВВБ — 100%,
зарядный кабель отключён. Владелец подтвердил: во всех пяти измерительных
Remote On двигатель и климат оставались выключенными.

Записано **1 563 506 кадров** с трёх CAN-шин. Измерительный сценарий:
три цикла Remote On / Remote Off и два цикла Remote On / Unlock / Lock.
Исходный файл также включает подготовку и восстановление связи; эти команды
не считаются дополнительными измерительными повторами.

В исходной выгрузке HA отдельной сущности оборотов нет. В последующем
сравнении обороты прочитаны из сохранённого сырого CAN по настройке трекера;
метод и ограничения приведены в отчёте сравнения.

Есть паузы приёма до **2,188 секунды**. Корректные CRC сохранённых пакетов
не означают полноту захвата трафика автомобиля. Подтверждённой команды
принудительного запуска ДВС эти данные не содержат.
