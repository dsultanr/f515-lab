# f515-lab

Разборы и заметки по головному устройству F515 (Android-гость под QNX-гипервизором, SA8155).

- [LAUNCHER_WIDGET_TWEAKS.md](LAUNCHER_WIDGET_TWEAKS.md) — три твика для виджетов главного
  экрана: разблокировка удаления «несъёмных» плиток, расширение виджета недавних приложений
  с 3 до 5 (в т.ч. вариант с закреплением избранных приложений вместо реальных недавних —
  см. ниже), и превращение виджета «Поездка» в панель переключения режимов автомобиля
  (Электро/Топливо) и вождения (ЭКО/Спорт). Готовые агенты, точки хуков, ключи
  `SeresPlatformAdapter`, интеграция в iSpace Toolbox.
- [PINNED_RECENT_APPS.md](PINNED_RECENT_APPS.md) — вариант твика `recent5`: вместо реальных
  недавних задач виджет закрепляет фиксированный список из 5 избранных приложений. Резолв
  `AppInfoModel` через `AppDao.getByName()` в фоновом потоке (Room падает на главном),
  форс-рендер через heap walk, и разбор, почему источник данных виджета не привязан к живым
  переключениям задач.
- [NETWORK_STATUS_TYPE_ICON.md](NETWORK_STATUS_TYPE_ICON.md) — разбор для разработчика
  iSpace Toolbox: твик «Статус сети» показывает уровень, но никогда не рисует тип сети
  (4G). Данные читаются верные — в агенте смещены на одну позицию id вьюх статус-бара:
  иконка типа `mobile_signal_system` не адресуется вообще, а уровень пишется в скрытую
  `mobile_signal_data`. С готовым фиксом и рекомендацией резолвить id по имени.
- [TOOLBOX_APK_INSTALL_FALSE_FAILURE.md](TOOLBOX_APK_INSTALL_FALSE_FAILURE.md) — разбор для
  разработчика iSpace Toolbox: установка APK с флешки проходит, но показывается как
  неудачная. Логи, доказательства успешной установки, три наблюдения (`fixupAppDir` −22 на
  съёмных томах, недоставленный `PACKAGE_ADDED`) и что с этим делать.
- [MEDIA_LISTEN_CPU_INVESTIGATION.md](MEDIA_LISTEN_CPU_INVESTIGATION.md) — почему
  `com.seres.media.listen` жёг 30-45% CPU при неиграющей музыке: профилирование, пять
  неудачных попыток починки и рабочий обход через `debug.hwui.fps_divisor`.
